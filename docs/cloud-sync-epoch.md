# 工作空间世代与旧设备救援

TimeGenie 使用工作空间世代（workspace epoch）隔离云端回滚前后的写入。未发生过回滚的工作空间世代为 1；此时旧版客户端缺少世代请求头仍可兼容。第一次云端回滚会把世代递增到 2，从此缺少世代或携带旧世代的写入都会被服务器拒绝。

## 设备收到世代变化时

- 没有旧世代待上传修改：停止普通增量同步，下载完整云端快照，以新世代继续同步。
- 存在 pending、failed、conflict 或 deferred 数据：进入“旧世代阻塞”，停止上传，保留本机业务数据与队列。
- Realtime 的 `workspace_reset` 只作为唤醒信号，不按普通实体写入本地；设备随后通过 pull 比较服务器世代。

## 救援旧设备数据

1. 在“设置 → 数据存储”确认出现旧世代阻塞横幅。
2. 前往“本地备份”，选择设备救援备份并保存文件。救援包不会包含令牌、设备授权、同步队列或可重放载荷。
3. 如需保留旧修改用于人工迁移，可把救援包恢复到独立本地工作空间查看。
4. 确认可以放弃旧修改后，点击“放弃旧修改并重新下载”。TimeGenie 会先自动生成本机安全备份，再只删除旧世代队列和延迟状态，最后下载新世代完整快照。

安全备份或云端下载失败时，阻塞状态、本机数据和旧队列保持不变，可再次尝试。首次使用云端回滚前，应升级账号下的其他设备；旧客户端在世代大于 1 后不能继续写入。
