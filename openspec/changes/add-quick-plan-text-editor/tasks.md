# Tasks

## 1. 计划文本与草稿模型

- [ ] 1.1 新增快速计划编辑纯逻辑模块，定义已有行、新建行、基线快照、最终树、行错误和变化摘要类型，并通过 TypeScript 类型检查验证类型可被组件与服务层复用
- [ ] 1.2 实现当前主体进行中事项到稳定行模型的序列化，保留 taskId、version、顺序和两级父子关系，并用测试验证重复标题仍保持不同身份
- [ ] 1.3 实现纯文本粘贴解析和规范化，支持无缩进、一个 Tab、两个空格、四个空格及空白新行，并用专项测试覆盖无父级子项、混合缩进、一或三个空格、超深缩进和列表符号按标题保留
- [ ] 1.4 实现基于稳定身份的新增、改名、父级变化、同级顺序变化和待删除差异计算，并用测试覆盖新旧事项混排、同名事项、清空已有行、移出子项后删除父项和无实际变化
- [ ] 1.5 实现父项资格预校验与分组变化摘要，逐项展开父子删除范围，并用测试验证重复事项、直接工时父项和删除数量/明细一致
