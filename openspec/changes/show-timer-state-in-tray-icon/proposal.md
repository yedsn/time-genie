# Proposal

## Why

当前 TimeGenie 托盘始终显示应用主图标，用户必须悬停、打开菜单或切回主窗口后才能判断计时器是否正在执行或已暂停。将托盘图标变为计时状态标识，可以让用户在不打断当前工作的情况下快速确认当前状态，并降低忘记暂停或忘记开始计时的概率。

## What Changes

- 将系统托盘图标改为可选的动态计时状态标识，只表达“执行中”“已暂停”“无当前事项”三种计时器状态。
- 默认提供同时使用图形和颜色区分状态的“状态圆标”，并提供参考 TokenBall 的“极简色块”样式。
- 在设置页的托盘行为区域增加托盘图标样式选项，并保留现有“应用图标”作为静态兼容选项。
- 在应用启动、计时开始、暂停、继续、结束、状态恢复及周期校准后刷新托盘图标与 Tooltip。
- Tooltip 在存在活动计时时展示状态、当前事项名称与累计时长；空闲时明确提示没有当前执行事项。
- Tauri 托盘与 Windows 原生备用托盘使用相同状态映射和设置，避免不同注册路径显示不一致。
- 不改变计时器状态语义、事项状态、悬浮面板内容或计时数据结构。

## Capabilities

### New Capabilities

- `tray-timer-status-icon`: 定义托盘图标对计时器三种状态的展示、样式设置、Tooltip 内容及状态刷新行为。

### Modified Capabilities

无。当前项目尚未建立主规格目录，本变更新增独立的托盘计时状态图标能力。

## Impact

- Tauri/Rust：增加动态 RGBA 托盘图标绘制、Tooltip 生成和统一刷新入口，并让现有托盘计时动作触发即时更新。
- Windows 原生备用托盘：支持运行时替换图标与 Tooltip，并管理动态 `HICON` 的创建和释放。
- 前端设置：在 `MainWorkbench.vue` 的托盘行为区域增加设备级图标样式选项，复用现有设置读写机制。
- 设置存储：增加设备级 `tray_icon_style`，不需要 SQLite 表结构或 Supabase Schema 迁移。
- 测试与验收：增加状态映射、图标绘制、Tooltip、设置回退和原生备用托盘更新路径的验证，并在实际 Windows 任务栏检查尺寸、深浅色可辨识性和即时刷新。
