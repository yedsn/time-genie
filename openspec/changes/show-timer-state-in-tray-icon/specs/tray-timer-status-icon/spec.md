# Spec Delta

## Purpose

该能力用于让用户仅通过系统托盘图标即可识别计时器当前处于执行中、已暂停或无当前事项状态，并允许用户选择适合自己的图标样式，同时保持 Tooltip 与实际计时状态一致。

## ADDED Requirements

### Requirement: 托盘图标表达计时器三种状态
系统 SHALL 使用托盘图标表达计时器的“执行中”“已暂停”和“无当前事项”三种状态，并且 MUST 使用不同图形轮廓区分状态，不能仅以颜色作为唯一识别方式。

#### Scenario: 计时器正在执行
- **WHEN** 当前计时器状态为 `running`
- **THEN** 动态托盘样式展示绿色执行标识及可辨识的播放图形

#### Scenario: 计时器已暂停
- **WHEN** 当前计时器状态为 `paused`
- **THEN** 动态托盘样式展示橙黄色暂停标识及可辨识的暂停图形

#### Scenario: 没有当前事项
- **WHEN** 当前不存在运行中或暂停中的计时记录
- **THEN** 动态托盘样式展示灰色空闲标识及区别于执行和暂停状态的空心或中性图形

### Requirement: 用户可以选择托盘图标样式
系统 SHALL 在当前设备的托盘设置中提供“状态圆标”“极简色块”和“应用图标”三种样式，并 SHALL 默认使用“状态圆标”。

#### Scenario: 选择状态圆标
- **WHEN** 用户选择“状态圆标”并保存设置
- **THEN** 托盘立即使用带状态图形与状态色的圆形标识，并在后续启动时继续使用该样式

#### Scenario: 选择极简色块
- **WHEN** 用户选择“极简色块”并保存设置
- **THEN** 托盘立即使用简洁状态色块，并保持三种状态的图形差异可辨识

#### Scenario: 选择应用图标
- **WHEN** 用户选择“应用图标”并保存设置
- **THEN** 托盘立即恢复静态 TimeGenie 应用图标，计时状态变化不再替换图标

#### Scenario: 读取未知或缺失的样式设置
- **WHEN** 设备中不存在托盘图标样式设置，或保存值不属于受支持的样式
- **THEN** 系统使用“状态圆标”作为安全默认值，并保持托盘可用

### Requirement: Tooltip 展示当前计时摘要
系统 SHALL 使托盘 Tooltip 与当前计时器状态一致；活动计时的 Tooltip SHALL 包含状态、当前事项名称和累计有效时长，空闲状态 SHALL 明确提示没有当前执行事项。

#### Scenario: 查看执行中事项
- **WHEN** 用户将指针停留在处于执行状态的托盘图标上
- **THEN** Tooltip 展示“执行中”、当前事项名称和已累计的有效时长

#### Scenario: 查看暂停事项
- **WHEN** 用户将指针停留在处于暂停状态的托盘图标上
- **THEN** Tooltip 展示“已暂停”、当前事项名称和暂停前累计的有效时长

#### Scenario: 查看空闲状态
- **WHEN** 用户将指针停留在没有当前事项的托盘图标上
- **THEN** Tooltip 明确展示“当前没有执行事项”

#### Scenario: 无事项计时正在执行
- **WHEN** 计时器正在执行但当前记录没有关联具体事项
- **THEN** Tooltip 使用现有计时记录标签作为名称，不显示空白事项名称

### Requirement: 状态变化及时刷新托盘展示
系统 SHALL 在计时状态发生已知变化后立即刷新托盘图标与 Tooltip，并 SHALL 周期性读取权威计时状态进行校准，以覆盖跨窗口、恢复和同步导致的状态变化。

#### Scenario: 开始计时
- **WHEN** 用户从任意受支持入口成功开始计时
- **THEN** 托盘在不需要重启应用的情况下切换为执行中展示

#### Scenario: 暂停或继续计时
- **WHEN** 用户成功暂停或继续当前计时
- **THEN** 托盘立即切换为对应状态展示，并更新 Tooltip

#### Scenario: 结束计时
- **WHEN** 用户成功结束当前计时且不存在其他活动计时
- **THEN** 托盘立即切换为无当前事项展示

#### Scenario: 周期校准发现状态不一致
- **WHEN** 周期校准读取到的权威计时状态与托盘当前展示不同
- **THEN** 系统将托盘图标与 Tooltip 修正为权威状态

#### Scenario: 状态读取暂时失败
- **WHEN** 托盘刷新期间无法读取当前计时状态
- **THEN** 系统保持最近一次有效图标与 Tooltip，不得错误地切换为空闲状态或影响计时操作

### Requirement: 所有 Windows 托盘路径保持一致
系统 SHALL 在正常 Tauri 托盘和 Windows 原生备用托盘中使用相同的状态、样式和 Tooltip 语义。

#### Scenario: 正常托盘可用
- **WHEN** 应用成功注册正常 Tauri 托盘
- **THEN** 正常托盘按照当前设置和计时状态展示图标与 Tooltip

#### Scenario: 启用原生备用托盘
- **WHEN** 正常 Tauri 托盘不可见并启用 Windows 原生备用托盘
- **THEN** 原生备用托盘展示与当前设置和计时状态对应的图标与 Tooltip，并响应后续状态变化

#### Scenario: 刷新托盘展示失败
- **WHEN** 某次图标或 Tooltip 更新失败
- **THEN** 系统保留可交互的最近一次有效托盘展示，并允许后续刷新继续重试
