- [x] 3.5 实现工时分配编辑器，支持将一段原始时间拆分到多个事项，并验证事项实际工时按分配结果汇总。
- [x] 3.6 实现手动补录和时间修正，验证修改时间范围后原始分钟数重新计算且现有分配重新校验。
- [x] 3.7 实现分配边界校验，验证分配超过原始工时时无法保存并显示超出分钟数。
- [x] 3.8 实现重新分配已结算工时，验证原始时间片保持不变且事项汇总工时正确更新。
- [x] 3.9 实现后台未归属时间累计、超过 5 分钟强制处理、分配到多个事项、休息和丢弃操作，并验证弹框打开期间时间继续累计。
- [x] 3.10 实现云端全局单计时器和后台采集设备租约，验证多台机器同时操作不会重复计时或重复累计未归属时间。
