- [x] 2.3 实现已知云端基线上的本地连续版本协调，验证暂停、继续、结束和归属连续发生时最终 payload 保留最新版本、segments、allocations 和工作日信息
- [x] 2.4 保留本地 Hook 与处理结果幂等记录，不让 outbox 压缩重复或漏发 `timer.started`、`timer.stopped`，验证自动化 Hook 回归测试通过
- [x] 2.5 增加离线开始、暂停继续、结束、确认归属后恢复网络的后端测试，验证同步后云端等价状态不丢时间片、不重复分钟
