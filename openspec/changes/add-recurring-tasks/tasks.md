- [x] 2.4 增加叶子事项约束，允许一级、二级及更深层级的无子事项启用重复，仅拒绝有子事项的事项启用重复；保存规则时在事务内校验当前是否存在子项，拒绝重复事项新增子项，并验证关闭重复后可以恢复普通层级编辑。

- [x] 3.2 扩展事项查询 DTO，返回重复规则摘要、查询日期、轮次来源和轮次状态，同时保持普通事项返回兼容；通过序列化和列表测试验证字段语义。
- [x] 3.3 调整今日事项查询，将普通事项规则与重复事项当天虚拟/持久化轮次合并，并保留原父级路径和排序；通过测试覆盖计划日、非计划日、开始日期之前、一级重复叶子事项保持一级，以及嵌套重复叶子事项保持原父级和层级。
- [x] 3.4 实现“跳过昨天，只显示今天一条”，确保连续多天未打开应用不会补建历史空轮次；通过跨五天测试验证数据库无多余 occurrence 且今日列表只有一条。
- [x] 3.5 调整全部待办和计时选择器查询，始终只返回一条重复事项定义并标识规则摘要；通过重复执行多天后的列表测试验证无同名副本。
