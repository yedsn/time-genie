- [x] 1.2 更新 `supabase/schema.sql`，为每个工作空间增加活动共享会话唯一约束及原子获取/创建、暂停/继续和处理契约，通过 SQL 测试验证两台设备并发创建只返回一个会话

- [x] 1.5 生成可重复执行且兼容旧客户端的 Supabase 补丁 SQL，并运行 schema 集成测试验证旧 time_entry-only 未归属处理调用及现有 RPC 保持可用
