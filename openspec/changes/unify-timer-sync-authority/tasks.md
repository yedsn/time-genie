- [x] 1.1 修改 `supabase/schema.sql` 和可部署补丁，使租约获取、续期、释放及未归属 tick 不再调用会修改普通事项计时的协调函数；添加 SQL/集成测试验证连续多次租约心跳不会改变活动 `time_entry`、segments 或 version
- [x] 1.2 保留云端计时补丁的版本、计时链、工作日期唯一性和设备权限校验，并为版本不匹配返回结构化当前版本及权威聚合；通过 RPC 测试验证客户端无需解析英文错误字符串即可分类

- [x] 1.4 定义并实现租约过期后的显式计时接管流程，使新设备先采用云端快照再生成恢复转换；通过双设备集成测试验证有效租约阻止竞争写入、过期接管不会由续租隐式改版本
