# Proposal

## Why

TimeGenie 已支持本地 SQLite 与 Supabase 多设备同步，但缺少可验证的数据备份、用户可读的云端操作记录，以及在误删、批量错误修改后恢复整个云端工作空间的能力。现有同步变更序列只服务于增量拉取，无法安全承担审计和历史恢复职责，因此需要补齐独立的数据保护能力。

## What Changes

- 新增本地数据备份包导出、格式校验和导入恢复；导入前自动生成当前数据的安全备份。
- 备份业务数据与允许迁移的非敏感设置，但排除系统凭据、Supabase 会话、设备授权、同步队列、冲突状态和运行时租约。
- 新增语义化云端操作记录，按一次用户或系统业务操作聚合展示操作者设备、来源、时间、摘要、受影响实体及字段差异。
- 新增云端工作空间的手动镜像、每日自动镜像和回滚前安全镜像，并支持查看镜像元数据和当前数据差异。
- 新增受控的云端工作空间原地回滚；回滚前检查活动计时、待同步操作和冲突，自动创建安全镜像，并通知其他设备重新构建本地缓存。
- 新增工作空间世代隔离。回滚后递增世代号，拒绝旧世代设备自动上传离线操作，并允许用户先导出设备救援备份。
- 首期不提供逐条操作撤销、单个实体局部恢复、跨账号恢复或多人协作权限模型。

## Capabilities

### New Capabilities

- `local-data-backup`: 本地备份包的导出、校验、导入恢复、安全备份及敏感数据排除规则。
- `cloud-operation-history`: 用户可读的云端业务操作记录、操作聚合、字段差异、筛选和保留规则。
- `cloud-workspace-snapshots`: 云端历史镜像的创建、预览、保留、原地回滚、恢复锁和多设备世代隔离。

### Modified Capabilities

无。项目当前没有已归档的主规格，本变更新增上述能力规格。

## Impact

- `src-tauri`：增加备份包读写与校验、导入事务、云端操作记录、镜像管理、恢复流程和世代校验命令。
- `src-ui`：在数据存储设置中增加本地备份、操作记录、历史镜像、差异预览、回滚确认和旧世代数据救援入口。
- `src-tauri/migrations`：增加本地备份/恢复所需元数据与工作空间世代状态迁移。
- `supabase/schema.sql` 及补丁 SQL：增加云端操作记录、镜像、恢复锁、工作空间世代字段、RPC、RLS 和保留清理能力。
- 云同步协议：所有可上传操作携带工作空间世代号；回滚后在线设备全量重建缓存，旧世代 outbox 不得自动重放。
- 测试与文档：补充备份往返、敏感数据排除、镜像差异、回滚失败恢复、多设备旧世代拦截和 Supabase RLS 验证。
