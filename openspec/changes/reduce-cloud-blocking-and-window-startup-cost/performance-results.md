# 性能验证结果

## 运行环境

- 日期：2026-10-25
- 系统：Windows x64
- Node.js：v22.19.0
- 浏览器：Chromium 153.0.8010.12（Playwright，无头模式，1280 × 720）
- 算法样本：固定两级事项树，1,000 / 5,000 条，各运行 25 次并记录 median 与 P95

## 大事项集基准

纯计算验收阈值：1,000 条单项 P95 ≤ 50ms，5,000 条单项 P95 ≤ 150ms。

| 规模 | 展示行 P95 | 筛选 P95 | 计时面板准备 P95 | 局部更新 P95 |
| --- | ---: | ---: | ---: | ---: |
| 1,000 | 1.35ms | 0.21ms | 0.08ms | 0.03ms |
| 5,000 | 3.37ms | 0.89ms | 0.17ms | 0.03ms |

浏览器验收阈值与结果：

| 规模 | 首次稳定阈值 / 结果 | 筛选阈值 / 结果 | 活动 DOM 行阈值 / 结果 |
| --- | ---: | ---: | ---: |
| 1,000 | 500ms / 55ms | 150ms / 11ms | 1,100 / 1,000 |
| 5,000 | 1,500ms / 115ms | 350ms / 24ms | 5,100 / 5,000 |

5,000 条场景未超过任何交互阈值，因此本变更不引入虚拟列表或分段渲染，避免增加树形拖拽、选择和滚动定位的复杂度。若后续真实页面基准超过同一阈值，再启用有界渲染。

## 构建分包基线

- 初始入口 JS + CSS：原始 1,734,539 bytes，gzip 456,445 bytes。
- HoverPanel：独立动态 chunk，gzip 约 2.31kB。
- MainWorkbench：独立动态 chunk，gzip 约 407.80kB。
- 报告、备份、云端历史、云端快照、自动化设置均形成独立动态 chunk。
- hover chunk 不包含 MainWorkbench、Markdown 编辑器或主窗口重量设置模块。
- Vite 构建无循环 chunk 警告，因此未增加 manualChunks。

## 请求与响应性边界

- main 冷启动固定为一次 workbench bootstrap，并复用其中的日历和主体数据。
- hover 冷启动只加载活动计时和未归属状态，不调用 bootstrap、完整事项树、报告或设置加载。
- 云端阻塞任务由 6 并发执行器隔离；慢任务测试中，轻量异步工作在 50ms 超时预算内完成。
- SupabaseClient 按规范化 Project URL + anon key SHA-256 指纹缓存，配置、登录账户和退出边界会清理缓存。

## 集成验收记录

自动化覆盖以下可复现场景：

- 弱网/超时及重试错误映射保持 `CLOUD_TIMEOUT`、`VERSION_CONFLICT`、`WORKSPACE_EPOCH_STALE` 等结构化结果。
- main/hover 并发慢请求由全局并发上限约束，轻量控制面无需等待业务请求完成。
- 计时开始、切换、暂停、恢复、停止在后台结果返回后更新托盘，原有调用顺序不变。
- 跨日继续使用独立日历 command 重新收敛；workspace epoch 和 Realtime 变化仍触发内存清理、领域失效和可见页面权威刷新。
- 现有网络 online 唤醒与 Realtime 边界验证保留并纳入最终回归。
