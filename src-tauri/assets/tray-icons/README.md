# 托盘状态图标来源

托盘三态使用 Iconify 收录的 Google Material Symbols Rounded 图标，不使用项目自绘轮廓。

- `material-symbols:play-circle-rounded`
- `material-symbols:pause-circle-rounded`
- `material-symbols:stop-circle-rounded`
- `material-symbols:play-arrow-rounded`
- `material-symbols:pause-rounded`
- `material-symbols:stop-rounded`

原始 SVG 可通过 `https://api.iconify.design/material-symbols/<图标名>.svg` 获取。Material Symbols 使用 Apache License 2.0。目录中的 `.alpha` 文件是对应 SVG 在 32×32 尺寸下生成的透明度蒙版，供 Rust 托盘渲染直接着色。
